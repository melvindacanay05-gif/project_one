RECIPE STUDIO
Project 1 / Web Programming
==============================

PROJECT OVERVIEW
----------------
Recipe Studio is a multi-page recipe website built with HTML and CSS. It presents recipes, provides information about the project and team, and uses CSS styling and transitions to create a consistent browsing experience.

TECHNOLOGIES
------------
- HTML5 for page structure and content
- CSS3 for layout, responsive design, themes, hover effects, and transitions
- No JavaScript, PHP, APIs, or databases are intended to be required

PROJECT FILES
-------------
- index.html       Homepage
- page_2.html      Recipe catalog / featured recipes
- about.html       About and contact information
- team-intro.html  Team introduction and project overview
- recipe.html      Rosemary Sea Salt Focaccia recipe
- recipe_2.html   Additional/legacy recipe page
- recipe_3.html   Egg, Ham & Cheese Croissant recipe
- recipe_4.html   Chicken Pesto Panini Sandwich recipe
- recipe_5.html   Southwest Chicken Wrap recipe
- recipe_6.html   Blueberry Muffin recipe
- recipe_7.html   Chamomile Tea recipe
- style.css        Shared website styles
- assets/          Images and other website assets

Some filenames or recipe descriptions may vary if the project has been updated.

FEATURES
--------
- Multi-page navigation between the homepage, recipe catalog, recipes, About page, and Team Intro page
- Light, Dark, and Ambient theme choices where included in the page markup
- CSS-only hover effects, zoom effects, fade-ins, and slide-in transitions
- Responsive layouts intended to work on desktop, tablet, and mobile screens
- Email links on the About page use mailto links
- Contact form fields are for visual demonstration; the form does not send messages
- Reduced-motion styling and visible keyboard focus cues where implemented

HOW TO OPEN LOCALLY
-------------------
1. Download and extract the project folder.
2. Keep the HTML files, style.css, and assets folder together.
3. Open index.html in a web browser.
4. Use the navigation menu to visit the other pages.
5. Test the theme controls and transitions on each page.

UPLOADING TO THE SERVER
-----------------------
Upload the HTML files, style.css, assets folder, and this README.txt to the same project directory on the web server. Preserve the folder structure so image paths and links continue to work. After uploading, open the hosted index.html and test the navigation and assets.
